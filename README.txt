# REDMAGIC Charger Website (Demo)

A responsive, dark gaming-style product landing page built with HTML, CSS and vanilla JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in your browser.

## XAMPP
Copy the `redmagic_charger_website` folder into `C:\xampp\htdocs\`.
Then visit `http://localhost/redmagic_charger_website/`.

## Customize
- Edit text and sections in `index.html`.
- Change colors, spacing and responsive styles in `style.css`.
- Cart demo and mobile menu are in `script.js`.

## Important
This is an independent demo storefront concept, not an official REDMAGIC website. It does not process payments or real orders. Confirm exact charger model, wattage, compatibility, included accessories and warranty with the seller before publishing product claims.
